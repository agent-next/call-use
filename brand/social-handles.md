## Naming Strategy: Consistency Guidelines

### Primary Brand Names (In Order of Preference)

1. **`call-use`** — Full, descriptive, matches domain
2. **`calluse`** — Compact, all platforms; use when hyphens not allowed
3. **`@calluse`** — Social media handle; standard form
4. **`@call_use`** — Fallback if hyphens not supported; use sparingly

### Avoid These

- `CallUse` (Capitalization inconsistent across platforms)
- `CallUse.io` / `call-use.io` (If domain is `call-use.com`, use only that)
- `calluse-ai` (Too long; doesn't add clarity)
- `usecall` (Reversal confuses brand)

## Platform-Specific Notes

### Package Registries

**PyPI Setup:**
- Repository: `github.com/call-use/call-use` (Python package)
- Package name: `call-use` (with hyphen; converts to `call_use` on import)
- First release: Tag as `v0.1.0` in GitHub
- Use `twine upload` to push to PyPI

**npm Setup:**
- Repository: `github.com/call-use/call-use` (or separate JS package repo)
- Package name: `call-use` (npm supports hyphens natively)
- First release: Tag as `v0.1.0`; `npm publish` from CI/CD

**Homebrew Tap:**
- GitHub repo: `call-use/homebrew-call-use` (required naming)
- Formula structure: `Formula/call-use.rb`
- Installation: `brew install call-use/homebrew-call-use/call-use`
- Users can alias: `brew tap call-use/homebrew-call-use` then `brew install call-use`

### Social Media: Platform-Specific Policies

**Twitter/X:**
- Verification badge: Apply once account has engagement history
- Handles marketplace: Can buy inactive handles if brand variation needed
- No character limit for bios; use full template

**GitHub:**
- Organization display name: "call-use" (user-friendly)
- GitHub username: `@call-use` (if claiming org handle separately)
- Org pages: Can customize landing page with markdown

**Mastodon:**
- Federation: Users from other instances can follow `@calluse@mastodon.social`
- No algorithm: Posts visible only to followers + reblogs
- Best for: Long-form thoughts, release announcements (audience smaller but engaged)

**Bluesky:**
- Custom domains: If `call-use.com` owned, verify and use `@call-use.com`
- Otherwise: Standard `@calluse.bsky.social`
- Growing platform; good for early adoption positioning
